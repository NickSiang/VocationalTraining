用 JavaScript 操作 DOM 樹 1.利用 document 的內建函數 createElement 來動態創造新的元素 2.修改元素的屬性 .textContent 來設定文字內容 3.接著用 .append() 函數來讓元素吃下別的元素，也就是「把另一個元素收為子元素」

===========================================
ex:
html:(before)

<div id="app"></div>

var heading = document.createElement('h1');
heading.textContent = '這是標題';

var para = document.createElement('p');
para.textContent = '這是段落文字';

var app = document.getElementById('app');
app.append(heading);
app.append(para);
===========================================
html:(after)

<div id="app">
  <h1>這是標題</h1>
  <p>這是段落文字</p>
</div>

.then() 是什麼？
.then() 是 Promise 物件的方法，它的主要作用是處理 Promise 解析 (resolve) 後的結果。
當 Promise 變成 fulfilled（成功狀態）時，.then() 會執行提供的回呼函式 (callback function)。


什麼是 Promise？
Promise 是 JavaScript 內建的 非同步處理機制，用來處理 異步操作（如 API 請求、讀取檔案、計時器等）。
Promise 有 三種狀態：
pending（待處理）：Promise 剛建立，還沒完成。
fulfilled（已成功）：非同步操作完成，並回傳結果。
rejected（已失敗）：非同步操作失敗，並回傳錯誤。
當 fetch() 發送請求時，它會回傳一個 Promise，並在成功時解析 (resolve) 得到 Response 物件（即 res）。

Response 物件是 fetch API 回傳的 HTTP 回應，它包含了伺服器回應的所有資訊，例如狀態碼、標頭（headers）、回應的內容（body）等。

總結
.then() 用來處理 Promise 成功的結果，第一個參數是成功時的回呼函式。
.then() 回傳一個新的 Promise，所以可以鏈式呼叫。
.catch() 處理 Promise 的錯誤，建議用 .catch() 而不是 .then(onRejected)。
.then() 與 fetch() 經常搭配，用來處理 API 回應資料。
