flex-direction 能讓資料從左往右放，也能由右往左， 或是在直向排列下也能控制是要從上到下或從下到上： flex-direction: row 資料流就是從左至右，從左邊開始 (左邊為起點，右邊為終點) row-reverse 資料流就是從右至左，從右邊開始 (右邊為起點，左邊為終點) column 資料流從上至下 從上方開始 column-reverse 資料流從下至上 從下方開始 justify-content 預設為 flex-start ， 這個屬性可以用來配至主軸的對齊方式， 包含對齊資料流的起點、終點、置中等等： justify-content: flex-start 左 flex-end 右 center 中 space-around 將空白區域給平分到每個 item 之間 邊邊沒有空隙 space-between 在每個 item 的左右加上均分後的空隙 邊邊會有空隙 flex-wrap flex-wrap 在 Flex 可以用來控制是否換行，預設的值為 nowrap 不換行 指定 flex-wrap 為 wrap 換行，那超過寬度的區塊就會自動被擠到下一行了 align-items 可以用來調整次軸的對齊方式， 配置的值和 justify-content相似： align-items: flex-start 替次軸對齊上 center 替次軸對齊中(垂直置中) flex-end 替次軸對齊下 flex-grow & flex-shrink 0就是不被壓或伸 flex-shrink Flex Box 內的區塊寬度超過的部分會自動被縮成與 Flex Box 的容器等大 flex-grow Flex Box 內的區塊寬度少於的部分會自動被伸成與 Flex Box 的容器等大
