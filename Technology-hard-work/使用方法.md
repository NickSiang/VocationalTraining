方法:<style scoped>作用

在 Vue 中，<style scoped> 是用來限制樣式的作用範圍，使其僅影響當前的組件，而不會污染全局或其他組件的樣式。
為什麼使用 <style scoped>？

1.防止樣式衝突： 當多個組件存在時，未加 scoped 的樣式是全局的，可能會意外影響其他組件的樣式。使用 scoped 可以確保樣式僅應用於當前組件。

2.提高組件的可復用性： 如果一個組件的樣式是獨立的，這個組件可以在其他項目中直接使用，而不需要擔心樣式衝突。

3.簡化樣式管理： 每個組件的樣式只影響自己，開發者可以更輕鬆地定位和修改樣式，減少調試時間。

1.製作子組件 ex:

選項式寫法

<script>
// Vue 中的組件配置，它定義了一個 Vue 組件，並通過 
// export default 將其導出，以便其他文件可以導入和使用它。
export default {
    props: {

        // 設置linkName來動態傳遞數據給當前組件
        linkName: {
            // 屬性字串
            type: String,
            // 預設頁面
            default: 'PageData01',
        }
    },
    created() {
        console.log(this.linkName)
    }
}
</script>

組合式寫法

<script setup>
const props = defineProps({
    linkName: {
        type: String,
    }
})
</script>

<template>
<!-- 讓這個元件可接收到頁面的內容
(this.linkName) -->
    <router-link :to="(this.linkName)"
        class="">
    </router-link>

</template>
